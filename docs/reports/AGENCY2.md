# AGENCY2 report (16:06 GMT)

State: typecheck, `npx vitest run` (83 files, 1550 tests) and `npm run build` are green. One real Calculator run passed; the Safari careers run was NOT done.

## What changed, in the requested order

1. **More automated by default.** `agency` now defaults to `ask_per_task` (src/shared/settings.ts). Profiles with `agencyChosen: false` and `off` or `ask_each` load as `ask_per_task` (src/main/settings.ts `load()`). The legacy-boolean paths (`reconcileAgency`, `coerceSettings`) use the same default. The prompt (prompts.ts) now says the plan is confirmed ONCE, the steps then run, a risky step still asks, and consent/cookie choices are left to the learner. One plan confirmation covers all steps: clicks, scrolls, waits and PLAIN TYPED TEXT (after it passes every text scan) run without another prompt. Return/Enter, other keys, `require_confirmation` from the model, low confidence and send-shaped words still ask. `open_for_me` asks once per open, as before (one action is the plan).
2. **Loop recovery.** Limits are 12 steps and 120 s; the per-minute backstop is 16. A repeated proposal no longer stops the task: the model gets `feedback` ("You already did X; the screen ... ; choose a DIFFERENT next step or finish"), up to 2 recoveries per task, then `gave_up`. One element is never clicked more than twice (the AX element's words, else a 40-unit screen cell). No visible change after an action: a short wait and a second capture, then ONE re-plan with feedback (the next click is re-grounded through the AX resolver); a second miss in a row ends the task. Stop and every cap still work.
   **Typing.** Likely root cause (not reproduced live): the confirmation prompt is in Alongside's own window, so after "Yes" the keystroke goes to the frontmost app, which can be Alongside instead of the browser. Fixes: the frontmost app is recorded BEFORE any prompt; before `type`/`keys`, if Alongside is in front, the target app is re-activated (`open -a`) and re-checked; a 350 ms focus pause after a click; if the screen did not change after typing, ONE retry through `actuator.pasteText` (previous clipboard text saved, text on the clipboard, Cmd+V, clipboard restored; text only, an image on the clipboard would not be restored), reported in the history and the audit ("type: paste fallback"). typeText's argv/escaping is unchanged. AX focus verification was not added on purpose: the AX resolver never reads text fields (privacy rule); the capture hash is the check.
3. **Policy.** Denylist gains agree, "i agree", consent, cookie(s), "allow all", "accept all" (label, target-text and typed-text scans stay strict; the tool result says "I leave consent choices to you"). The GOAL scan removes negated clauses first (do not, don't, never (not "never mind"), without, avoid, "leave ... alone"), up to the next period, semicolon, or ", and/then/but". Tests: 'open View open roles, do not sign in or submit anything' passes; the real Safari goal passes; 'sign in to my bank', 'pay the bill', 'do not sign in, then pay the bill', 'never mind, buy it' are blocked.
4. **Scope.** New src/main/agency/scope.ts: the goal names the target (browser family for web goals, Calculator and a few native apps, else the first app seen). The frontmost app is read with `lsappinfo` (no permission prompt) at the start, at the top of every step and right before every action. Another app, or Claude / a terminal (Terminal, iTerm, Ghostty, Warp, ...), stops the task with a plain message; Alongside/Electron windows are allowed. Every audit line carries `app`. `ALONGSIDE_AGENCY_SCOPE=0` turns it off.
5. **Preflight.** New rows: a WARN for headless Chrome processes ("N headless Chrome processes may swallow links opened for you; quit them or use Safari"; 10 exist on this Mac right now, not killed) and an "Agency" row with setting, loop flag and Accessibility. The full preflight was not run (syntax check only).
6. **Path hardening.** Already in place: `checkPath` resolves real paths for the file and the roots (symlink escape), covered by tests/agency/path-symlink.test.ts. No change needed.
