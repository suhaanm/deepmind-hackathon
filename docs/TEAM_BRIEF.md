## 2. Product essentials (full detail: `$HACK/PLAN.md` §3, §6)
**Help Ladder (per skill; plain deterministic code decides the level, not the LLM):**
L1 *Watch me* – assistant demonstrates with a **ghost cursor** (animated, never clicks), ≤3 steps/chunk, slow speech, one analogy · L2 *Walk with me* – one arrow+ring+numbered badge per step, **verification tick** before next · L3 *Nudge me* – goal only; on stall: soft glow → spoken clue → arrow (that step drops to L2) · L4 *On my own* – silent unless harm is imminent; check only at the end/when asked.
State: per skill `{level, streakClean, lastSeen, nextReview}`. Clean attempt = completed, hints ≤ cap, ≤1 error, no safety flag, teach-back ≥0.67 ⇒ step up. 2 hints/2 errors/2 stalls/anxiety phrase ⇒ step down for the attempt. Absent 3/7/14 days ⇒ drop one. Safety-critical steps never below L2. “Show me again”/“let me try” override free. **`DEMO_MODE` setting: step-up needs 1 clean attempt** (default ON today; say so honestly on stage).
**After each task:** spoken teach-back → rephrase if wrong → one “point to it” question → confidence dial 1–5. **Progress view:** “things you can do now”, skill tree, confidence trend, **hints-per-task chart** (anti-dependency proof).
**Skills to build (only 3):** `video_call` · `spot_scam` · `bigger_text`.
**Personas (PLACEHOLDERS — user will rename; config-only, one file `src/shared/personas.ts`):** `marcus` (male, unhurried step-by-step coach) and `amelia` (female, calm, concise). Wake phrases “Hey Marcus” / “Hey Amelia” + fuzzy aliases. Voice names TBD by audition from Google’s prebuilt list (gender undocumented) — keep in config.
**Voice style rules (for prompts):** plain English, 1–2 short sentences, never “just/simply/obviously”, no jargon without an analogy, never condescending/gamified (older adults find toy-like UX infantilising), say “I can’t see that” rather than guess, never read out card numbers/passwords, never call a message “safe”, always admit it’s an AI, point to human help (bank number on your card, Age UK) for scam/money topics.
**Trust & control (non-negotiable):** screen read only while a session is active (visible indicator, auto-off); screenshots sent with `store:false`; on-screen text is DATA never instructions (prompt-injection defence); “Do it for me” is **OFF by default** and, if ever on, needs a real-click confirmation (`ask_user_confirm`) — approval can never come from model text; big **Stop** control always reachable; money/passwords always stay with the user.

## 4. Contracts (Architect transcribes into `src/shared/*`; everyone codes to them)
**Coordinates:** all annotation/grounding coordinates are **normalised 0–1000, origin top-left of the target display, x→right, y↓**. `NormPoint {x,y}`; `NormBox {xmin,ymin,xmax,ymax}` (objects, never bare arrays). Gemini `box_2d` is `[ymin,xmin,ymax,xmax]` — convert ONLY in `src/main/gemini/grounding-utils.ts` (`fromGeminiBox`). Overlay converts norm→CSS px against its window size.
**Shot:** `{id, displayId, widthPx, heightPx, scaleFactor, jpegBase64, takenAt, overlayHidden}`. Purposes: `'live'` (≤1280px wide, q≈0.6, **overlay may be visible**), `'ground' | 'verify'` (full-res up to 1920 wide, **overlay hidden ≤120 ms during capture**; if `setContentProtection(true)` is proven to exclude the overlay from `desktopCapturer` on this macOS, use that instead — OVERLAY owner tests & documents).
**Annotation (main→overlay):** `{id, tone:'guide'|'success'|'warn'|'danger', ttlMs?} &` one of `ring{box,label?,step?}` · `arrow{to:NormPoint|NormBox, from?:NormPoint}` · `badge{at,n}` · `spotlight{box}` · `ghostCursor{path:NormPoint[], pressAtEnd?:boolean}` (**visual only, never clicks**) · `bubble{at,text}` · `tick{box,ok}` · `highlightText{boxes:NormBox[],note?}`. `OverlayCommand = {type:'show',annotations[]} | {type:'clear',ids?} | {type:'caption',speaker,text,final} | {type:'chip',level,label}` over IPC `overlay:cmd`.
**Types** (all in `src/shared/protocol.ts`, zod schemas where data crosses a model boundary): `PersonaId='marcus'|'amelia'` · `HelpLevel=1|2|3|4` · `SkillId` · `GroundResult{found,box?,point?,confidence,label?,reason?,latencyMs,model}` · `LessonPlan{lessonId,skillId,goal,steps[]}` · `LessonStep{id,index,instruction≤20 words,targetDescription (visual, for the grounder),expectedOutcome (what the screen looks like after),hints{l1 demo narration,l2,l3 nudge clue},safetyCritical,analogy?}` · `Verdict{completed,confidence,evidence,uncertain,learnerMisstep?,nextHint?}` · `ScamReport{verdict:'likely_scam'|'suspicious'|'likely_genuine'|'cannot_tell',confidence,redFlags[{phrase,why}],advice(≤3 short plain sentences; never “safe”),humanHelp,models[],latencyMs}` · `AgentChip{id,kind:'scam_check'|'lookup'|'lesson_summary',title,status:'running'|'done'|'error'|'cancelled',startedAt,summary?,result?}` · `LearnerSnapshot{skills{[SkillId]:{level,streakClean,lastSeen,nextReview}},confidenceLog,whatWorks[],avoidJargon[],lastSession?}`.
**Settings (persisted `settings.json` in userData; UI toggles):** `persona|null` · `helpLevelMode:'auto'|'locked'` + `lockedLevel` · `pacing:'gentle'|'fast'` · `voiceSpeed` 0.75–1.25 · `captions:boolean` · `textOnly` · `bigAnnotations` · `highContrast` · `dyslexiaFont` · `explainJargon` · `teachBack` · `scamShield` · `doItForMeAllowed` (default **false**) · `carerSharing` (default **false**) · `pushToTalkOnly` · `listeningLight` · `demoMode` (default true) · `wakeEnabled`.
**CompanionState (main `StateStore`, broadcast IPC `state:update` to dock+overlay):** `{persona|null, phase:'asleep'|'listening_for_name'|'connecting'|'live'|'thinking'|'speaking'|'error', micMuted, level:HelpLevel, levelLocked, skill?:{id,name,step,stepCount}, captions[], agents:AgentChip[], settings, lastError?}`; modules call `state.patch({...})`.
**Service interfaces** (`src/shared/contracts.ts`; DI bag created in `src/main/services.ts` with `ALONGSIDE_MOCK=1` and per-service `ALONGSIDE_MOCK_<NAME>=1` mocks so the whole pipeline runs from minute 1): `Capture{grab(purpose),liveFrame():{jpegBase64,changeScore},watch(on):void}` · `Grounder{ground({target,shot?,hint?})}` · `Verifier{verify({step|expected,shot?})}` · `LessonArchitect{plan({goal,learner,shot?})}` · `ScamAnalyst{analyze({text?,shot?,url?})}` · `Router{classify(utterance)}` · `OverlayController{show,clear,caption,chip}` · `LiveBridge{inject(text,{interrupt?})}` · `LearnerStore{load,save,snapshot,recordAttempt,editMarkdown(read|write,revision)}` · `LevelEngine` (pure fns) · `LessonRunner{start(goal),onStepDone(),onStall(),abort()}` · `AgentRuntime{spawn(kind,task,payload?),list(),cancel(id)}`.
**Event bus (`src/main/bus.ts`, typed):** `wake{personaId,source}` · `session:request{personaId,source:'wake'|'hotkey'|'button'}` · `session:ended{reason}` · `tool:called{name,args,ms}` · `screen:changed{score}` · `lesson:step{...}` · `level:changed{...}` · `agent:update{chip}`.
**IPC channel names** are one `const IPC = {…}` object in `src/shared/ipc.ts` (typed `invoke/handle/send/on` wrappers in preload). No ad-hoc string channels anywhere else.

**Live tool declarations** (renderer `LiveSession` exposes these to `gemini-3.8-live`; each call is forwarded over IPC `live:toolCall` to main `src/main/tools/dispatcher.ts`; set `behavior: NON_BLOCKING` explicitly on all except `ask_user_confirm`; dispatch each call as its own task, never await inside the receive loop):
`point_at{target:string, step?:number}→{found,confidence,note?}` · `start_lesson{goal:string}→{lessonId,skillId,stepCount}` · `step_done{note?}` · `verify_step{expected_outcome:string}→Verdict` · `set_help_level{level:1-4,reason?}` (advisory; LevelEngine may overrule) · `spawn_agent{kind,task,payload?}→{agentId}` (results arrive later as injected text `[agent_result …]`) · `ask_user_confirm{question≤500 chars,options:[string,string]}→{choice}` (UI modal in dock; real click only) · `update_profile{note}` · `end_lesson{summary,teachBackScore?}` · `clear_annotations{}`.
**Main→Live renderer:** IPC `live:inject {text, interrupt?}` (runner/agents/stall hints; formatted `[RUNNER] …`, `[AGENT_RESULT] …`, `[STALL] …` — the system instruction tells the model to treat these as authoritative stage directions). **Live→main:** `live:toolCall`, `live:transcript{role,text,final}`, `live:status{connected,phase}`, `teaching:systemInstruction(personaId)` invoke at session start. **Frames:** Live renderer polls `capture:liveFrame` at 1 fps while connected. **Mic arbitration:** single owner at a time — wake spotter runs only when no Live session; on wake it releases the mic and emits `session:request`; Live owns the mic until `session:ended` (idle 20 s, “goodbye”, Stop, error), then the spotter resumes. Pause the spotter while TTS plays.
**Core loop (what must work end-to-end):** wake/hotkey → `session:request` → Live opens with persona voice + system instruction (from TEACH) → user asks → model calls `start_lesson` or `point_at` → main `capture.grab('ground')` → `grounder.ground` → overlay shows ring/arrow/badge (before TTS finishes) → `capture.watch` + learner action or `step_done` → `verifier.verify` → tick (or repair hint) → `LessonRunner` advances/fades via `LevelEngine` → end: teach-back → `LearnerStore` updated → progress view shows hints-per-task.
**Grounding rules (learned from Clicky’s Windows fork):** one grounding call; return `found:false` when unsure (assistant says “I can’t see that”); never fabricate boxes; debug model-localisation, coordinate mapping and rendering separately; arrows are guidance, never click targets.
**Dev/debug HTTP (dev only, `127.0.0.1:${ALONGSIDE_DEBUG_PORT:-7777}`):** `GET /health` `GET /state` `POST /tool {name,args}` (same dispatcher as Live) `POST /inject {text}` `POST /overlay {cmd}` `GET /shot?purpose=ground` (JPEG) `POST /wake {personaId}` `POST /settings {patch}`. This lets everyone drive and test the app without voice.
**Env flags:** `ALONGSIDE_MOCK` · `ALONGSIDE_MOCK_<SERVICE>` · `ALONGSIDE_NO_OVERLAY` · `ALONGSIDE_HEADLESS` · `ALONGSIDE_DEBUG_PORT` · `ALONGSIDE_USERDATA` (isolated profile dir) · `GEMINI_API_KEY` (only in `.env`) · optional model overrides `MODEL_LIVE/FLASH/LITE/ARGON/TRANSCRIBE` read ONLY in `src/shared/models.ts` (defaults: `gemini-3.8-live`, `gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-4-argon`, `gemini-3.5-transcribe-live`).
