**Chat bus (renderer, `src/renderer/dock/chat/bus.ts`, DESIGN creates it in its first 10 min):** `type ChatMessage={id:string;role:'user'|'assistant';text:string;final:boolean;at:number;via:'voice'|'typed'}`; `chatBus={push(m):void /*upsert by id, cumulative text*/, subscribe(cb:(msgs:ChatMessage[])=>void):()=>void, send(text:string):void /*UI → controller*/, onSend(cb:(text:string)=>void):()=>void, clear():void, mode():'voice'|'text', setMode(m):void, onMode(cb):()=>void}`. LIVE's `dock/controller.ts` pushes transcripts (user + assistant, voice) into the bus and registers `onSend` to send a typed user turn to the Live session (starting a session with the default persona if none is active, without the microphone when mode is `text`); in `text` mode audio playback is muted and the mic is off, replies show as chat bubbles.
**Permissions IPC (SHELL owns; additive to ipc.ts/preload):** `window.alongside.permissions = { status(): Promise<{microphone:PermState; screen:PermState; accessibility:boolean}>, requestMicrophone(): Promise<boolean>, requestAccessibility(): boolean /*opens the system prompt*/, openSettings(pane:'screen'|'microphone'|'accessibility'): void, relaunch(): void, onChange(cb): ()=>void }` where `PermState='granted'|'denied'|'not-determined'|'restricted'|'unknown'`. Main uses `systemPreferences.getMediaAccessStatus`, `askForMediaAccess('microphone')`, `isTrustedAccessibilityClient`, and `shell.openExternal('x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture|Privacy_Microphone|Privacy_Accessibility')`.
**Actuator (OVERLAY owns `src/main/actuator/**`):** `interface Actuator{status():{accessibility:boolean; dryRun:boolean}; openUrl(url):Promise<ActResult>; openApp(name):Promise<ActResult>; revealPath(path):Promise<ActResult>; openSettingsPane(pane):Promise<ActResult>; clickAt(p:NormPoint,opts?:{double?:boolean}):Promise<ActResult>; typeText(text:string):Promise<ActResult>; pressKeys(combo:string):Promise<ActResult>; scroll(p:NormPoint,dy:number):Promise<ActResult>}` with `ActResult={ok:boolean; reason?:'accessibility'|'blocked'|'dry-run'|'failed'; detail?:string}`. `openUrl` allows only http/https (no credentials, no `javascript:`/`file:`/`data:`), via `shell.openExternal`; `openApp` sanitises the name (letters/digits/space/dot/dash), uses `open -a`; click/type/keys/scroll need Accessibility (`systemPreferences.isTrustedAccessibilityClient(false)`), use osascript System Events, `typeText` max 300 chars, `pressKeys` allowlist (return, tab, escape, space, arrows, cmd+l/t/w/v/c/a/f, cmd+shift+4 is NOT allowed). `ALONGSIDE_ACTUATOR_DRYRUN=1` logs instead of acting; tests must use it.
**Agency (AGENCY owns `src/main/agency/**`, `docs/AGENCY.md`):** policy engine (ported ideas/code from the Windows fork's hermes plugin permission tiers + safety policy), tools `open_for_me{kind:'url'|'app'|'file'|'settings', value}` (Tier 1, no screenshot) and `act_for_me{goal}` (agentic loop on Gemini's `computer_use` tool, ≤8 steps, fresh screenshot per step, never auto-retries, each action shown on screen as ring + ghost cursor BEFORE executing, approvals via the existing `ask_user_confirm` real-click flow, Stop kills it, audit log `userData/actions.log` mode 0600), plus OVERLAY's `do_it_for_me{target}` single click. Hard denylist (pay/purchase/buy/order/checkout/send/submit/delete/remove/erase/transfer/confirm/sign in/log in/password/card/allow/grant/install/accept, any safetyCritical lesson step, scam context, anything in a password field) — the assistant then shows instead of doing. `agency='off'` ⇒ every tool returns `{allowed:false}` and the assistant teaches instead.
**Teaching principle for agency:** always offer a choice ("I can open it for you, or show you how — which would you like?"); after doing, narrate what was done in one sentence and offer to show how next time; count it (`doneForMe`) so the progress view can show dependency honestly.
**Files/RAG (FILES owns `src/main/files/**`, `src/renderer/dock/files/**`):** consent per folder via a native dialog, local index in userData, read-only, tool `search_files{query,k?}` returning ≤3 short snippets with file paths, IPC `files:*` (addFolder, removeFolder, list, status, reindex, deleteIndex), progress in state.
**Showtime (DEMO owns `src/main/showtime/**`, `assets/showtime/**`, `src/renderer/overlay/annotations/Roadmap.tsx`, `docs/SHOWTIME.md`):** IPC `showtime:start|stop|next|prev|pause|state`, bus event `showtime:request`, dock button + tray item + hotkey call it. Two modes: `scripted` (default for stage: deterministic, no model calls, pre-rendered narration clips, ground-truth boxes from `__stage.rects()`) and `live` (real services). A discreet **"Scripted walkthrough"** badge shows by default (hide with `ALONGSIDE_SHOWTIME_BADGE=0`); after the tour the app stays in normal live mode for Q&A.
