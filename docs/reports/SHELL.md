# SHELL report: menu bar, permissions, login item

## What shipped
- `src/main/tray.ts`: macOS menu-bar item (template icons in `resources/tray/`, generated by `resources/tray/generate.mjs`: ring with a small orb; idle, live, muted variants). Left click shows the dock or toggles collapsed/expanded; right click pops up the menu: status line, Talk to <persona A/B> (hotkey shown only if actually registered), Type instead, Mute/Unmute microphone, Stop (enabled only in a session), Show/Hide panel, Run the demo walkthrough, Set up again…, Permissions…, Quit Alongside. Created/destroyed live by `showMenuBarIcon`. Skipped when `ALONGSIDE_HEADLESS=1`. `window-all-closed` no longer quits while the tray exists; the dock window hides instead of closing.
- `src/main/permissions.ts`: `status/requestMicrophone/requestAccessibility/requestScreen/openSettings/relaunch/onChange` per TEAM_BRIEF_V2 §3. Status adds `probe` ('ok'|'empty'|'error'|'skipped'), `needsRestart`, `hint` (names the launching Terminal app via the process tree, or Electron/Alongside). Screen is 'granted' only if a `desktopCapturer` probe (3 tries) returns a real thumbnail. `status()` never makes macOS prompt; only `requestScreen()` does. Polling is 1.5 s only while subscribed.
- `src/main/login-item.ts`: `launchAtLogin` applied at startup and on change; no-op with a log line in dev builds and off macOS.
- Settings: `showMenuBarIcon` (true), `launchAtLogin` (false).
- IPC: `permissions:*` channels, `shell:command` (main to dock; `src/shared/shell.ts`), types in `src/shared/permissions.ts`; `window.alongside.permissions` and `.shell.onCommand`. Debug HTTP: `GET /tray`, `POST /tray/click {id?}`.
- Shared edits: `windows.ts` (`showDock/hideDock/isDockVisible/getDockMode`, close hides), `bus.ts` (`showtime:request` entry for DEMO), `index.ts`, `ipc.ts`, `preload`, `debug-server.ts`.

## Verified
- `src/main/{tray,permissions,login-item}.test.ts`: 68 tests with an Electron mock (menu content, labels per phase, icon choice, click handlers, every permission branch, probe retries and caching, change feed start/stop, login item guards).
- Real run (`node resources/tray/real-check.mjs` under the lock, 22/22 pass, `docs/shell-shots/real-check.json`): tray exists with bounds 38x33; `permissions.status` over real IPC returns granted/granted/true, probe ok, hint text; Talk to Amelia sets persona and phase live; Mute sets micMuted and the muted icon; Stop ends the session; Hide/Show panel flips the label; icon off/on via setting; icon crop in `docs/shell-shots/tray-icon.png`.

## Fix pass (mac findings)
- "Type instead": main/tray.ts never saved textOnly; the dock App.tsx mirrored every chat-mode change into settings.textOnly. The tray command now calls `chatBus.setMode('text', { transient: true })` (additive option in `dock/chat/bus.ts`; `onMode` listeners get `{ transient }`), and App.tsx skips persisting transient switches. Talk|Type in the chat still persists as before. Tests: `bus.test.ts` (transient flag), `tray.test.ts` (no settings patch).
- `main/session.ts`: `confirm.cancel()` now runs before the inactive-phase early return in `session:ended`, so Stop always clears a pending confirmation. New `src/main/session.test.ts` (3 tests).
- Verified: typecheck clean, vitest on session/tray/bus 35 passed, build ok. Not run in real Electron.
